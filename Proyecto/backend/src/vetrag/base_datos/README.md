# base_datos/ — Conexión y tablas de PostgreSQL + pgvector · ⏳ pendiente

Conexión a la base de datos y definición de la tabla de chunks (texto, metadatos y vector).
La tabla de usuarios vive en el módulo `auth/`, que no se publica.

Los **datos** de las tablas nunca se suben al repositorio: contienen texto de los libros.
