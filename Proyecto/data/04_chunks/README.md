# 04_chunks/ — Fragmentos listos para vectorizar (F2) · ⏳ pendiente

Aquí quedarán los chunks en formato `.jsonl`: un fragmento de ~800 tokens por línea con sus
metadatos (documento, especialidad, ruta de títulos, página e idioma). Son la entrada del
paso de vectorización con Voyage AI.

## ¿Por qué no se sube a GitHub?

Cada chunk contiene texto literal de los libros (derechos de autor).
