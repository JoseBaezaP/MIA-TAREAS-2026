# 02_ocr/ — PDFs con capa de texto (F2) · ⏳ pendiente

Aquí quedarán las copias de los PDFs aprobados en la F1, procesados con
`ocrmypdf --skip-text -l spa+eng`: a las páginas que solo tienen imagen (escaneos) se les
agrega una capa de texto invisible, y las páginas que ya tienen texto no se tocan.

## ¿Por qué no se sube a GitHub?

Son copias de los libros originales (derechos de autor, varios GB).
