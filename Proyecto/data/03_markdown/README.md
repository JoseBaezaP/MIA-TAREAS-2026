# 03_markdown/ — Documentos en Markdown (F2)

Un archivo `.md` por documento (`libro.pdf` → `libro.pdf.md`), con la misma ruta de carpetas
que en `assets/`. Cada uno empieza con una cabecera de metadatos (documento, especialidad,
idioma, fuente, páginas) y tiene una marca invisible `<!-- pagina: N -->` antes del texto de
cada página, para poder citar la fuente.

- `manifiesto.csv`: resultado de la conversión de cada documento (páginas, páginas vacías,
  páginas leídas como texto plano, caracteres).
- La limpieza (quitar encabezados repetidos, datos personales y corregir unidades) es el
  paso siguiente.

## ¿Por qué no se sube a GitHub?

Es el texto completo de los libros (derechos de autor) y todavía puede tener datos personales.
