# 03_markdown/ — Documentos en Markdown (F2) · ⏳ pendiente

Aquí quedará cada documento convertido a Markdown con `anydoc` y ya limpio (sin
encabezados ni pies de página repetidos, números de página, índices, etc.), conservando
títulos, tablas y marcas de página para poder citar la fuente.

Es el texto completo de los libros (derechos de autor).
